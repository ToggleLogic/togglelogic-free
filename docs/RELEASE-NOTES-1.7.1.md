# ToggleLogic Free 1.7.1

ToggleLogic Free 1.7.1 is an owner-scoped patch release paired with private
ToggleLogic Intelligence 1.5.1. It packages the production-tested SAM
chief-of-staff, skill-choice, and calendar-routing corrections made after 1.7.0.

## Chief-of-staff behavior

Safe draft-only writing can pass through without requiring an external delivery
tool. Requests to send, publish, upload, or use live/private source data remain
governed and fail closed. Incidental mentions of an installed tool no longer
override a compatible deterministic workflow recipe unless the owner explicitly
asks to invoke that skill.

## Explained skill choices

When a genuine ambiguity remains, the owner sees each installed skill's verified
purpose and configured mailbox/account identity. An incomplete catalog explicitly
reports that purpose metadata is unavailable; it never presents an unexplained
bare identifier as a meaningful choice.

## Owner calendar and meeting preparation

Appointments and personal daily schedules resolve deterministically to Microsoft
Graph. A request that asks for plural meetings to be prepared composes Microsoft
Graph with Zoom meeting history. The exact production incident wording is a
regression fixture and bypasses the probabilistic classifier.

Schedule requests now receive the same authoritative calendar truth contract as
meeting, appointment, and agenda requests. The schedule recipe is deliberately
narrow: personal schedules for today/tomorrow resolve to Graph, while project,
production, and filming schedules for a generic named day do not.

Full-day Graph reads must use owner-local midnight through the following local
midnight as an exclusive boundary, including the correct offset for that date.
Repeated records are normalized by stable event identifiers and identical
time-slot duplicates are disclosed without being counted as separate meetings.

Meeting preparation is not complete merely because the calendar and Zoom history
were checked. Each verified meeting must include supported attendee/company
context, likely purpose, objectives, decision points, risks, specific talking
points, and recommended follow-ups, with sourced facts separated from advice.

The trusted parent also removes meeting join links, meeting IDs, passcodes, and
dial-in PINs from every bounded-child result before delivery, even when those
values appeared in an authoritative calendar body or location.

## Compatibility and safety

This release preserves the owner-scoped boundary, bounded children, model-family
architecture, cloud budget, execution receipts, tool guard, and fail-closed
calendar verification of 1.7.0. The paired Intelligence release changes only
release compatibility metadata; its routing engine is unchanged.
