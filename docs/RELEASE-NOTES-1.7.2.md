# ToggleLogic Free 1.7.2

ToggleLogic Free 1.7.2 is an owner-scoped routing-correctness patch paired with
private ToggleLogic Intelligence 1.5.2.

## Incidental skill names stay contextual

An installed skill name appearing inside pasted data is no longer sufficient to
execute that skill. A CRM import whose rows say “LinkedIn,” for example, routes
to the CRM action unless the owner actually asks for LinkedIn research. Explicit
`use`, `run`, `via`, or named `skill` instructions continue to work.

## One eligible lineage needs no menu

When first-use evaluation leaves exactly one reachable, accepted, capable, and
within-budget model lineage, ToggleLogic executes it for that turn instead of
asking the owner to reply `1`. It does not store a permanent preference. Any
real alternative, budget exception, stale profile, or requirements conflict
continues through the existing owner-bound education flow.

## Compatibility and safety

The release preserves owner scope, bounded child execution, tool guards, cloud
budget enforcement, durable model-family targets, and execution-time resolution
to a concrete child. The observed investor-import prompt and both independent
review edge cases are permanent regression tests.
