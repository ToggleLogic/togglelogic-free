# ToggleLogic Free 2.0.0

ToggleLogic Free is once again a generic routing and enforcement connector.
The 1.6–1.7 application-orchestration surface has moved back to the consuming
application, where identity, memory, workflow contracts, integrations, artifact
authorization, and user-facing behavior belong.

This is a major release because the prior application-specific configuration and
public planning/run tools are removed. The generic routing, audit, approval,
cost-visibility, and optional Intelligence seam remain.

For SAM deployments, upgrade the private SAM orchestration adapter and the
compatible Intelligence release before enabling ToggleLogic Free 2.0.0.
