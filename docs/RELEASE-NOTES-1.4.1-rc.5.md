# ToggleLogic Free 1.4.1-rc.5

This private release candidate replaces the dense technical execution line with
a short, human-readable receipt. Model, location, one-use approval, usage, and
cost each appear on their own line, with the cost emphasized at the end.

The detailed provider reference and pricing source remain available in
ToggleLogic's machine-readable audit data; simplifying the displayed receipt
does not remove governance evidence.
